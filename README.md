# 🚀 Welcome to My C++ Learning Journey!

> **Friendly greeting!** This repository contains my complete implementations of the C++ modules from the **[Codam](https://www.codam.nl/)** / **[42 Network](https://42network.org/)** curriculum.

---

## 🎯 What's Here?

A comprehensive collection of C++17 implementations focusing on:
- **Object-Oriented Programming (OOP)** principles
- **Memory management** and low-level control
- **Core language features** and modern C++ idioms
- **Polymorphism** (ad-hoc, subtype, and through interfaces)
- **Templates** and STL mastery

---

## 📚 Module Breakdown

| Module | Topic | Key Concepts |
|--------|-------|--------------|
| **CPP00** | Basics | Namespaces, classes, member functions, `stdio` streams, initialization lists, `static`, `const` |
| **CPP01** | Memory | Memory allocation, pointers to members, references, `switch` statements |
| **CPP02** | Polymorphism & Operators | Ad-hoc polymorphism, operator overloading, **Orthodox Canonical** class form |
| **CPP03** | Inheritance | Base classes, derived classes, inheritance hierarchies |
| **CPP04** | Abstract Classes | Subtype polymorphism, abstract classes, interfaces |
| **CPP05** | Repetition & Exceptions | Exception handling, error management, repetition patterns |
| **CPP06** | Casts | C++ casting (`static_cast`, `dynamic_cast`, `const_cast`, `reinterpret_cast`) |
| **CPP07** | Templates | Template functions, template classes, generic programming |
| **CPP08** | STL Containers | Templated containers, iterators, algorithms |
| **CPP09** | STL Applications | **RPN** (Reverse Polish Notation), **Ford-Johnson** sorting algorithm |

---

## 🚦 How to Use

Each module is organized in its own directory. Navigate to a module folder and:

```bash
# Compile (example for cpp00)
make

# Run
make run

# Clean
make clean
```
